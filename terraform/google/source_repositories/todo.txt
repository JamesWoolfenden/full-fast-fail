## google_sourcerepo_repository

Cloud Source Repository pubsub_configs must specify an explicit service account (HLD_GCP_300)
When service_account_email is omitted from a pubsub_configs block, GCP automatically uses the Cloud Source Repositories service agent (service-PROJECT_NUMBER@sourcerepo-service-account.iam.gserviceaccount.com). This agent may hold permissions beyond what is strictly needed to publish to the configured topic. An explicit, dedicated service account limits blast radius, makes the IAM grant auditable in code, and satisfies least-privilege requirements.
